Multisensoric head using Profinet and IO-Link



gitlab link

Goal of this project is to develop self-contained device, that will be able to communicate using
Profinet and IO-Link protocols. Goal is to make it compact and user-friendly with focus on
universality. The device will be able to display all relevant information about a given industrial
process on a remotely accessible web page. The final product can be attached to a robotic arm or
another component of an automated production line.

In this blog series I will describe, how the project was made. I would like to include some
interesting parts of code, CAD design or any other part of my journey. I find this topic very
interesting, but also not well documented, so I'll do my best to change that.
